# Cracker Burst → I LOVE YOU ❤️

Upload `index.html`, `style.css`, and `script.js` to your GitHub repository root.

GitHub Pages:
**Settings → Pages → Deploy from a branch → main → /(root)**

Clicking **💌 Click Me** starts colorful cracker/firework bursts with generated crackling and boom sounds. After the main burst, **I LOVE YOU ❤️** appears with a rainbow neon effect.

Sound is generated with Web Audio, so no MP3 file is required. The first click is necessary because browsers block automatic audio until the visitor interacts with the page.

Change the final message in `index.html`:
`<div>I LOVE YOU</div>`
