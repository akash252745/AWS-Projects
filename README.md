# Bell Message GitHub Pages 🔔❤️

A page with an animated bell. When someone clicks the bell, the same special message appears while hearts continuously float upward.

## Upload to GitHub

Upload `index.html`, `style.css`, and `script.js` to the **root** of your repository.

Then:

1. Open **Settings**
2. Open **Pages**
3. Source → **Deploy from a branch**
4. Branch → **main**
5. Folder → **/(root)**
6. Click **Save**
7. Open the generated Pages URL.

## Change the message

Edit this in `index.html`:

```html
<h1>You are Special!</h1>
<p>Thank you for being<br>a wonderful part of my life.</p>
```
