# Pratibha Rainbow Heart ❤️

A GitHub Pages animation based on the supplied reference image.

### Included effects

- 100 continuously moving `I love you` elements forming the heart
- Pink neon glow around the heart text
- Large **Pratibha** in the center
- Cursive/script-style name
- Animated rainbow gradient across the name
- Pulsing/blinking brightness and size
- Neon multi-color glow
- Colorful twinkling star/sparkle effects around the name
- Responsive mobile layout
- No image file is required; the animation is generated with HTML/CSS/JS

## GitHub Pages setup

Upload:

- `index.html`
- `style.css`
- `script.js`

to the root of your repository.

Then your existing configuration remains:

**Settings → Pages → Deploy from a branch → main → /(root)**

## Change the name

In `index.html`:

```html
<div class="name" aria-label="Pratibha">Pratibha</div>
```

Change `Pratibha` to another name.

## Change the message

In `script.js`:

```javascript
<div class="love_word">I love you</div>
```

Change it to any message you want.
