# I Love You Heart + Pratibha ❤️

This version keeps the same heart animation mechanism and adds **Pratibha** in the center.

### Center name
`Pratibha` is:
- fixed in the center of the heart
- continuously blinking/pulsing
- changing through pink, purple, blue, green and yellow
- surrounded by a glowing effect

## GitHub Pages

Upload these three files to the root of your repository:

- `index.html`
- `style.css`
- `script.js`

Then use:

**Settings → Pages → Deploy from a branch → main → /(root) → Save**

## Change the name

In `index.html`, change:

```html
<div class="name">Pratibha</div>
```

to any name you want.
