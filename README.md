# I Love You ❤️ Pratibha — GitHub Pages

This is the final version of the moving-heart project.

## Features

- Same 100-element moving `I love you` heart animation
- Same staggered `--i` animation delays
- Same horizontal + vertical CSS animation mechanism
- `Pratibha` fixed in the clear center
- Name is above the moving heart elements, so the words do not overlap it
- Name continuously blinks/pulses
- Name changes glow color
- Responsive on mobile

## Upload

Upload these files to the repository root:

- `index.html`
- `style.css`
- `script.js`

Then use your existing GitHub Pages configuration:

**Settings → Pages → Deploy from a branch → main → /(root)**

## Change the name

Edit this in `index.html`:

```html
<div class="name">Pratibha</div>
```
