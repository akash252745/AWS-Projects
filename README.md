# I Love You Animated Heart ❤️

Upload `index.html`, `style.css`, and `script.js` to the root of a GitHub repository.

Then use:
Settings → Pages → Deploy from a branch → main → /(root) → Save.

The animation creates a heart shape from many moving/fading `I love you` words.

To change the repeated message, edit `script.js`:
`el.textContent="I love you";`
